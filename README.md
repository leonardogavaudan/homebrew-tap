# Homebrew tap

Casks for apps by Leonardo Gavaudan.

```sh
brew install --cask leonardogavaudan/tap/utter
```

| Cask | App |
|---|---|
| `utter` | [Utter](https://github.com/leonardogavaudan/utter): context-aware voice typing with your own API keys |

The `utter` cask is updated automatically when a new Utter release is published.
